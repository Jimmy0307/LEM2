1. Put CSV/XLSX/XLS files into: real_data\local\
2. Optional schema: real_data\schemas\<same-filename>.schema.json
3. Optional UCI data: paste UCI ID or DOI into real_data\uci_sources.txt
4. Double-click run.bat

If the target column is exactly one of target/class/label/decision, a schema is optional.
Otherwise create a schema file so the program does not guess the decision column.
