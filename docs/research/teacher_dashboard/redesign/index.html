NEW ALGORITHM PROTOTYPES · GATE 4

衝突感知切點：三個候選設計 EXPLORATORY · 非正式最佳

  • FCP_HIST：每特徵直方圖上以「條件熵 + 跨 Client 純但不一致的質量」貪婪選切點。結果：與 EW3 差異不顯著；去掉衝突項後表現相同 → 負面結果。
  • LOCO_SELECT：每個候選切點集合讓 Client 用「其他 Client 的規則」評估自身資料（留一 Client），以 BA、衝突、規則數挑選。去掉衝突懲罰反而更好 → 衝突項是負貢獻。
  • FED_MD_HIST／FED_MD_XC：把 Nguyen–Skowron 辨識切點法改成聯邦形式；目標「無法辨識的異類物件對」可分解為 Client 內 + 跨 Client，兩者都只需加總型計數。增益最大且接近集中式參考；強調跨 Client 對（XC）沒有額外好處。

結論方向：有效的不是「懲罰衝突」，而是保存全域可辨識性的切點。這是既有 Rough Set 離散化思想的聯邦化，不宣稱新穎演算法；最接近的先行研究見報告（Wozniak et al. 2026；Flores et al. 2026）。
