05 · METHODS / LIMITATIONS

給教授的研究定位與下一步

這一輪跑了什麼

每個資料集採用最多六個預先固定的候選特徵；同一份資料先進行 64／16／20 Development／Validation／Test 分割，Development 依 IID 或 Dirichlet label skew 分配給三個 Client。各 Client 使用相同特徵集合與相同 Target，局部尋找精確最小 Reduct、歸納 LEM2 規則，再合併去重。

下一輪不直接混入主結果

原始 Features >6 的 162 筆，後續才執行 `k=8/12/ALL` 或受資源約束的特徵選擇消融，另測 Client 數／跨 Client 特徵異質性。重新訓練必須固定 Test 分割及資源預算，並將結果保留在獨立實驗版本，不能覆蓋這一輪六特徵基準。

六特徵怎麼選：PMLB 與 OpenML 主要排除識別欄後依原始欄位順序選前六項；大部分 UCI 依來源順序取前六項，少數八筆事先設定業務／避免標籤洩漏的欄位。這不是資料驅動的最優六特徵。三個 Client 各自擁有最多六個相同 Features，不是把六特徵平均切成三份。

本輪研究限制：資料來源同源家族依賴、六特徵上限、HFL 相同 Schema／Target、四情境中的三客戶端模擬與 label-skew fallback、尚有九個資料集未完成、不同資料量的 CPU／時間複雜度、以及沒有執行完整 Feature Budget × Client Count 的消融。
