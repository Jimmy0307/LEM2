03 · TRAINING COVERAGE VS UNSEEN TEST

Training Coverage 能否提高？提高後 Test 與 Accuracy 會如何變化？

固定 Train-only 補充規則：放寬一個 IF 條件、規則在訓練集上的純度至少 90%、至少五個支持物件。補充後「覆蓋率」與原始 LEM2 規則覆蓋率不同，且可能引入新衝突。Baseline 再使用 Global Strength 預測，介入只針對原本無規則匹配的物件。
