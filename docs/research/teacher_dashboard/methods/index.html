00 · METHOD SCOPE AND REPEATED SPLITS

42 Seeds 是 Classical reduct + LEM2 的重複切分，不是 42 種演算法

本網站主矩陣的每個實驗均使用 Classical Rough Set 的正域保持最小基數 Reduct，集中式一次歸納規則；Federated C2–C5 則由各 Client 各自 Classical reduct + LEM2 後合併規則。所有版本的六種決策策略在固定的規則集合上選答案，並非六套不同 Reduct。

已完成 42 Seeds × 3 datasets × 2 splits × 5 rule-learning configurations × (NONE + 6 policies) = 8,820 列，其中 Federated 有 7,056 列。Non-IID 的先導結果與 DRSA／LERS 的未完成路線必須分開列示，不能混在正式基線。

pp = percentage point（百分點）：70% → 75% 是 +5 pp，但相對增幅為 (75−70)/70 = +7.14%。研究的配對比較 Δ(pp) = (B−A) × 100，不能把絕對 pp 差異直接稱為相對百分比改善。

Seed 1、7、21、42 的「多寡」是重複切分的數量；增加 Seed 旨在估計同一資料集的切分敏感性，不會讓資料集變多、也不自動提高準確率。查看 42-Seed 跨方法、五配置與穩定度互動對照 →

02 · ROUGH SET AND LEM2

Rough Set／Reduct／LEM2 的數學位置

對同一決策表，令 U 為物件全集，C 為條件屬性，d 為決策欄，P ⊆ C。對傳統不可分辨關係：

IND(P) = {(x,y) ∈ U×U : ∀a ∈ P, fa(x)=fa(y)}
LowerP(X) = {x ∈ U : [x]P ⊆ X}
POSP(d) = ⋃decision class X LowerP(X)
γP(d) = |POSP(d)|/|U|

本次程式的約簡準則：在所有 P ⊆ C 中，找最小基數且滿足 |POSP(d)| = |POSC(d)| 的候選。若有多組同樣大小，保留全部候選並依標準化的字典順序取一組給 LEM2 使用。

LEM2：在約簡後的條件空間針對決策概念的確定區域形成局部覆蓋，輸出 IF–THEN 規則。這個規則集合 R 本身不會自動等於唯一分類答案。

集中式

Train → P* → LEM2 → Rcentral

只對整份 Train 建一個 Rule Set。

聯邦式

Train → {Di} → {Pi*} → {Ri} → Union/Dedup → Rglobal

Local Rule Sets 先各自完成，合併後才進入共同評估層。當前 Global 支持度在所有訓練 Client 的資料上核對。

重要界線：上述是 Classical Rough Set 的相等不可分辨關係與正域約簡。DRSA（Dominance-based Rough Set Approach）必須另外定義準則單調方向、優勢關係及向上／向下近似；目前不應將 Classical reduct 的結果稱作 DRSA reduct。
03 · MATCHING AND CONFLICT

Match、候選集合與 Conflict 的操作性定義

MR(x) = {r ∈ R : Antecedent(r) 符合 x}
CandidateR(x) = {decision(r) : r ∈ MR(x)}
ConflictR(x) = 1[|CandidateR(x)| > 1]
指標公式／分母意義及限制
Overall Coverage#有任一匹配規則的物件 / #全部評估物件是否有規則可用；與預測是否正確不同
Target Coverage by Class各真實類別 d 中有任一匹配規則的物件數 / 該類測試物件數按類別分組的 Coverage；不能冒充正確候選覆蓋
True-in-Candidate#真實類別在 Candidate(x) 的物件 / #全部評估物件真實答案有沒有被任何匹配規則提出
Target Candidate Coverage by Class各真實類別 d 中 d∈Candidate(x) 的物件數 / 該類測試筆數比 Target Coverage 更嚴格
Conflict Case Rate#候選類別至少 2 種 / #全部評估物件候選歧義，不等於預測錯誤，也不是 Boundary Region
Conflict-resolution Accuracy#衝突物件中答對的筆數 / #衝突物件只有衝突子集的預測準確率
No MatchMR(x) = ∅原程式以訓練多數類別作 Fallback；可能答對或答錯

Conflict 後真正能處理的四種情況

無匹配規則

處理 Coverage、規則泛化、缺失與 Fallback。

正解不在 Candidate

回頭改善規則生成；換策略也選不到不存在的正解。

正解在 Candidate，但 Winner 錯

對照六策略分數、重複支持與類別分母。

最後 Winner 正確

仍需標記是否因 Fallback，及對 Seed／Client 順序的穩健性。

04 · CLASSIFICATION POLICIES

六種決策策略在同一個 Rule Set 上怎麼算？

令 Md(x) = {r∈MR(x) : decision(r)=d}。對各決策類別 d 的規則支持度：

Td = Σr∈Md |S(r)|（可重複支持數量）
Ud = |⋃r∈Md S(r)|（唯一支持人口）
Nd = #訓練資料中決策為 d 的物件
Pd = Ud/Td（非冗餘比例，T=0 時由程式按 0 處理）
程式核對後的權重更正：集中式 STANDARD 透過 fit_rule_weights 計算符合 Antecedent 的所有訓練物件數；聯邦式 STANDARD 透過 global_rule_support_context 重新在所有 Client 上計算符合 Antecedent 及規則決策的支持數。因此，聯邦式的 STANDARD 類別分數等於 Td，但集中式不一定等於 Td。PS、GS、PG 的 U／N／T 仍根據正確支持集合計算。
策略當前程式定義主要特性
FIRST_MATCH按順序找到第一條符合 antecedent 的規則，即回傳其 decision早停；Client 到達／規則順序可能影響 Winner
SIMPLE_VOTINGScore(d) = |Md(x)|每條規則一票
STANDARD_VOTINGScore(d) = Σr∈Md weight(r)規則權重加總：集中式為符合前件的訓練物件數；聯邦式為所有 Client 中前件且決策一致的支持數
GLOBAL_STRENGTHScore(d) = Ud / Nd類別人口正規化；對少數類別更有利，但不保證普遍最優
POPULATION_STANDARDScore(d) = Ud去除重複支持人口
POPULATION_GLOBALScore(d) = Ud²/(Nd Td)GS × Pd，額外懲罰支持重複
文獻界線：Population 修正是本研究自訂方法。不能說它是原典 LERS，也不能以此直接宣稱改善。不同比較應使用同一 Rule Set、相同測試物件，且保存最後 Winner、分數、同分決策。
同分處理：在得分相同的類別中，若訓練多數類別也在同分集合就選它；否則依決策值字串排序。當無規則命中，選訓練多數類別 Fallback。
05 · EVALUATION AND INFERENCE

分類績效、統計檢定與解讀界線

指標數學定義如何處理？
Accuracy(TP+TN)/N（二元時）；多類別為全部答對數／全部評估筆數整體平均；多數類別比例高時可能虛高
RecalldTPd/(TPd+FNd)真實類別 d 中被正確辨識的比例
Balanced Accuracy(1/K) Σd Recalld各類別等權平均
PrecisiondTPd/(TPd+FPd)被預測為 d 的結果中，真正為 d 的比例
Macro-F1(1/K) Σd 2PdRd/(Pd+Rd)類別等權，兼顧錯誤預報與漏報
Paired seed deltaΔs = Metric(A,s) − Metric(B,s)相同資料、Seed、切分與 Client 的條件下比較；先定義每 Seed 跨資料集的等權平均

研究限制：42 Seeds 為固定三資料集的重複切分，不能把 8,820 列當成 8,820 個獨立樣本；即使做成對 Wilcoxon 或 bootstrap，也必須處理同源資料的依賴與多重檢定。

Full Data / 80:20：FULL_DATA 用全部資料訓練又評估，是回代指標。HOLDOUT_80_20 用 80% 訓練與 20% 未見資料測試。兩者 Accuracy 差異不能簡單解讀為切分造成的因果效應。
