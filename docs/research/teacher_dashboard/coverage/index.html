01 · THREE DIFFERENT COVERAGE DEFINITIONS

先把規則覆蓋與拒判嚴格分開

Exact Rule Coverage#至少一條 IF 命中 / N

我們目前的 Coverage。無命中規則即 No Match；無論最後 fallback 是否答對，仍算沒有規則覆蓋。

True Candidate Coverage#真實類別在候選 / N

需要測試標籤才能離線計算，不能在未知標籤的線上推論拿來選擇策略。它衡量是否有機會從規則中選對。

Selective Acceptance Coverage#系統接受自動分類 / N

只有引入明確 reject／abstain 門檻後才有這個指標。目前的 No Match 預設多數類別，並非正式拒判。

C_train = |{x ∈ Train : M_R(x) ≠ ∅}| / N_train
C_test = |{x ∈ Test : M_R(x) ≠ ∅}| / N_test
Gap(pp) = 100 × (C_test − C_train)
NoMatch_test = 1 − C_test
Selective Risk = #接受後答錯 / #被接受；Acceptance = #接受 / N

在同一 Seed、資料集、Client 數下，必須以 Train 建立前處理／Reduct／Rules，再以完全相同的規則集合評估 Train 與未見 Test；不能用 Full Data 回代的 Coverage 直接減掉 Holdout Coverage，因為規則和訓練樣本不同。

來源診斷對應措施預期風險
未見過的特徵組合Test 條件組合在 Train 不存在，且沒有符合規則訓練集內的補充規則、部分匹配、較粗粒度規則可能增加錯誤候選與衝突

05 · VERIFIED PRIOR RESEARCH

已有人研究 Train/Test 覆蓋落差、補充規則與拒判權衡

  1. Inuiguchi & Washimi（2015），Improving Rough Set Rule-Based Classification by Supplementary Rules：針對新物件沒有任何規則完全命中，使用補充規則改善；最值得先做同方法比較。正式論文
  2. Discretisation of conditions in decision rules induced for continuous data（2020）：實測指出部分離散化與最小覆蓋方案的測試集規則覆蓋甚至可能接近零，並分析規則歸納與離散化方式的效應。PLOS ONE
  3. Błaszczyński 等（2011），Sequential covering rule induction algorithm for variable consistency rough set approaches：VC-DomLEM 使用放寬一致性門檻的近似，允許更廣的規則覆蓋範圍，但不保證未見資料的準確率會提升。期刊摘要
  4. El-Yaniv & Wiener（2010），On the Foundations of Noise-Free Selective Classification：區分接受率與在被接受子集的錯誤風險，為拒判率控制提供風險－覆蓋權衡框架。JMLR

VC-DRSA 更適用於屬性有明確偏好方向、決策有序的資料。若為 Car Evaluation 這類混合語意，必須先驗證方向、單調限制與有序類別，不能直接把 Classical LEM2 的結果改名 VC-DRSA。若「K4」是文獻中的特定演算法或參數，目前仍需準確來源確認；不要把它和四個 Client 的 C4 混稱。

06 · RESEARCH HYPOTHESES & GATES

接下來要如何真正提高 Test Coverage，而不是只調高分數？

候選方案改動範圍可證偽假設必要品質門檻
A0 原始完全匹配Classical LEM2 不變固定 42 Seeds 的 Test Coverage 與 Conflict 作基線與原 8,820 逐筆或逐配置一致
A1 No Match 才用部分匹配推論後處理，不重訓規則可增加「取得規則答案」的比例報告新增答對率；不能冒稱原始 Exact Coverage 已增加
A2 Train-only 補充規則額外規則生成並保存來源部分舊規則沒覆蓋的物件可被更一般規則涵蓋Rule Count、Conflict、BA、No Match、Train/Test Gap 一起比較
A3 訓練資料內調整一致性／粒度VC-IRSA、VPRS 或經驗證的約簡敏感性實驗減少確定規則太窄造成的缺口禁止使用 Test 調參；按類別比較正確候選與錯誤率
A4 加入明確 Reject／Abstain獨立選擇性預測門檻可在指定錯誤上限下決定接受率，而非盲目降低拒判輸出 Risk–Coverage 曲線，門檻在 Train-validation 選定

研究順序：先跑同規則 Train/Test Coverage → 把 No Match 分成新組合與舊組合 → 對相同 Seed 的 No Match 子集評估 A1／A2 → 再考慮 A3 VC-DRSA。把改善率寫成「新增接受的物件數與其正確率」，才有辦法判斷有沒有實際價值。

補充規則必須由 Train（含內部 validation）建立，Test 僅使用凍結模型評估；所有變更另建版本，不覆寫 Classical 8,820 基線。
