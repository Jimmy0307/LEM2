02｜每個指標究竟代表什麼？

每個指標的分母、所處的計算階段，以及改善方向都不同。以下數值若沒有預測能力，會明確標記為「未定義」。

指標公式／分母代表的意義可採取的改善措施
Pure LEM2 Rule Count|R|（條）LEM2 產生的規則數量，不代表準確率檢查規則冗餘、約簡與泛化能力；不能只求愈少愈好
Reduct最小基數 P*，保持 POS 的大小產生規則時保留哪些條件屬性確認特徵是否造成失真；此處是 Classical，不是 DRSA
Coverage#至少匹配一條規則 / #評估物件模型是否有規則可用先處理 No Match、特徵離散化或特定類別規則缺口
True-in-Candidate#真實類別在匹配規則候選中 / #評估物件正確答案是否有機會被選出候選缺失時改規則學習與資料治理，靠投票救不了
Conflict#候選決策類別 ≥2 的物件 / #評估物件候選規則互相提出不同類別先記錄衝突，再分析 six policies；不等於粗集合 Boundary
Accuracy正確預測數 / #全部評估物件整體正確率；類別不平衡時可能失真同時看 BA、Macro-F1 與每類 Recall
Balanced Accuracy(1/K)Σ 每一類 Recall少數類別也獲等權重檢查每類候選覆蓋與類別分母
Macro-F1(1/K)Σ 2PR/(P+R)所有類別的 Precision 與 Recall 折衷看混淆矩陣、誤報與漏報
Conflict resolution Accuracy正確預測且衝突 / #衝突物件只考慮已進入衝突的物件比較六策略在相同衝突集合下的表現
Population T / U / PT=支持次數；U=不重複支持物件；P=U/T辨識重複計數；P 越小代表重疊越多比較 STD 與 PS、GS 與 PG，不能保證修正有正增益
避免誤用：Conflict 高不等於 Accuracy 一定低；Conflict 0 不代表 Coverage 100%；真正需要分開比較的是「規則生成問題」與「已提出正確候選後的排序問題」。

03｜規則發掘與 Conflict 處理的正確流程（按順序）

此圖與原程式分層一致：Centralized 與 Federated 是兩條不同的規則產生路徑；一定要完成 Local LEM2 才能合併 Local Rule Sets。NONE 與六策略是在 Rule Set 產生後才分支，兩者不是先後順序。

兩種 Rule Set 各自進入相同評估層：Rule Matching → 候選決策集合。這裡會產生 Coverage、No Match、True-in-Candidate、Conflict 等診斷。接下來分成：

NONE：只分析、不強迫選 Winner

完整 Matching，測 Coverage 與 Conflict；沒有定義 Accuracy 或 Macro-F1。純 LEM2 則更早停在規則集合，不進入逐筆比對。

六種分類方法：計算 Winner

FIRST 依順序早停；其他五種完整收集命中規則後計分。比較 Accuracy、BA、Macro-F1 與每筆錯誤類型。

研究邊界：本次 Reduct 為 Classical 正域保留，不是 DRSA Dominance。Federated 規則支持度由全部訓練 Client 的資料計算；對象不同，不能把「合併後支持度」誤寫成「僅來源 Client 支持度」。

05｜Conflict 後要怎麼辦？一個明確的決策流程

① 沒有規則命中

候選集合為空，六策略都使用訓練資料多數類別作 Fallback；須另外稽核其是否剛好正確。

改善：擴充規則／特徵、評估預設類別與 Abstain
② 有規則，但正確類別不在候選

六種選擇方式都不能從現有候選中選出真實類別。

改善：改善 Reduct／LEM2 歸納、分割資料品質及局部類別偏斜
③ 多個候選，其中包含正確類別

這才是六種選擇策略能真正施力的情況。保留命中規則並比較得分。

改善：比較 GS/STD/PS/PG，檢查類別支持比例與重複支持
④ 不確定且風險高

可增加人工覆核或拒答門檻，但這是尚未驗證的新決策機制。

改善：先設定 Abstain／Review Gate，再做對照試驗
六種策略計分與 Conflict 公式 
M(x)={r ∈ R : Antecedent(r) matches x}
Candidate(x)={decision(r):r ∈ M(x)}
Conflict(x)=1 if |Candidate(x)| > 1 else 0

FIRST:         第一條命中的規則（依順序早停）
SIMPLE:        Score(d)=命中且屬於類別 d 的規則條數
STANDARD:      Score(d)=Σ weight(r)，集中式為前件匹配數；聯邦式為全Client正確支持數
GLOBAL:        Score(d)=U_d/N_d
POP STANDARD:  Score(d)=U_d
POP GLOBAL:    Score(d)=U_d²/(N_d × T_d)

T_d=支持集合大小的總和（可重複）
U_d=不重複支持訓練物件數
N_d=類別 d 的訓練物件數
P_d=U_d/T_d

同分：訓練集多數類別若在同分集合則優先，否則依字串排序。
Conflict 是本研究的「跨類別命中」定義，不是 DRSA／Classical Rough Set 的近似邊界。候選衝突率屬於規則集合的屬性，不會因改用 GS 或 STD 而直接降低；它們改變的是選出的 Winner。
