本研究的主要對象是 Federated LEM2（聯邦式粗糙集規則學習）：我們要計算聯邦式在 IID、Non-IID 與不同 Client 條件下，六種規則決策策略的準確率、Coverage、Conflict 與適用性。Centralized／Classical LEM2 僅作對照基準，用於衡量分散學習造成的差距，不是主要優化目標。

證據包括 181 個公開資料集完成四情境的全量實驗（各情境 5 seeds，來源規模上限 1,000,000 列）及最早三資料集的 42 seeds 比較。全量資料仍保留集中式紀錄以進行同條件配對；研究結論以聯邦三種情境為主，不能把不同批次的成績直接混算。

六種方法是什麼？

六種方法用的是同一組 LEM2 規則，差別只在「多條規則同時命中、答案又不一樣」時怎麼決定最後答案。

FM 第一條命中規則：用第一條命中規則的答案。SV 簡單投票：每條命中規則一票。STD 支持度投票：依規則支持的訓練筆數加權。GS 全域強度：支持筆數除以該類別訓練筆數。PS 去重支持度：同 STD，但同一筆訓練資料只算一次。PG 去重全域強度：同 GS 並去重。PS、PG 是本研究自訂的方法。

2聯邦式六策略哪個方法比較好？

比較基準更正：本節「0.24 pp、1.37 pp」不是聯邦－集中式的效益，也不是相對於多數類別的效益。

本表是歷史版5 Seeds數據（集中式184份、IID181份、α=0.5有182份、α=0.1有182份；各情境成功來源數不同），不等於上面最新179份完整來源×42 Seeds的固定共同母體。

這裡「平均落後最佳」的比較對象是同一資料集、同一情境，在六種決策策略中，根據Test Accuracy事後挑出的最高平均值；這只是用來描述六策略差異的 Oracle gap（事後最佳落差）。不能當部署效能，也不能說FM比集中式差多少。

真正的計算基準（每個資料集各自比較，再跨來源等權平均）： 落後最佳(d,s,p) = MAX[同資料集d／同情境s／6種策略q的5-Seed平均Test Accuracy] − [策略p的5-Seed平均Test Accuracy] 本格數值 = 該情境所有可用資料集的上述落差之算術平均；pp=百分點。

例如：假設某資料集在IID情境，六種方法的最高5-Seed平均Accuracy為75%，FM只有73%，則FM落後該資料集事後最佳2 pp。每個資料集都算一次這種差距，最後取平均；首頁的1.37 pp是這類落差的平均，不代表FM的絕對準確率，也不是與集中式的差異。

實驗報告應優先展示有明確對照基準的比較：例如最新179份完整來源×42 Seeds，固定STV＋A版本：集中式60.15% → Fed IID 62.45%（+2.30 pp），Fed α=0.5為59.02%（−1.12 pp），Fed α=0.1為53.41%（−6.73 pp）。這三個Δ的基準都是同一來源／同一Seed／同一策略下的集中式 STV＋A，不是六策略中的Test最佳值。若看B2，則需另外明寫「B2−A」且固定同一策略。查看最新完整配對與方法限制。

老師要看懂：不能只給平均準確率，要知道誰贏、贏多少、在哪些資料集贏。

研究重點是聯邦情境下六策略的表現：沒有任何方法永遠最好；聯邦 Client 資料越不均，策略差距越大，SV 在高偏斜條件下勝出最多。集中式一欄只作參照。

3聯邦式相對於集中式，效能差多少？

老師要看懂：聯邦式在同一訓練／測試切分與相同 LEM2 方法下，與集中式基準相差多少；目的是評估聯邦式的成本與適用條件。

以集中式為基準觀察聯邦效能：Client 資料相似時，聯邦表現接近集中式；資料越偏斜，聯邦通常下降。這不是要證明集中式較好，而是定位聯邦式需要改進的條件。

研究定位：集中式只是實驗對照組，六策略與 Client 分布的分析仍以聯邦為主。比較條件：同一個 seed 的 Train／Test 切分完全相同（已檢查每個 seed 的測試筆數一致），離散化、約簡、LEM2 與六種方法都相同。唯一差別是聯邦把訓練資料分給各 Client，各自學規則後再合併。

為什麼 α=0.1 的 Coverage 是 100%？

資料高度不均時，有些 Client 只拿到單一類別。這種 Client 的最小約簡是空集合，學出「不看任何條件，一律判為 d」的規則（TRUE→d）。這種規則會命中所有測試資料，所以 Coverage 變成 100%，但它其實沒有判斷力。扣掉這類規則後，真正有條件的規則命中率低很多：

5Training／Test Coverage 有什麼差異？

老師要看懂：為什麼訓練資料上的規則有用，到了新資料卻可能無法判斷。

無法判斷的原因有兩種，而且大部分屬於第一種：規則根本沒覆蓋到訓練資料，不是測試資料太新。

原因一：訓練資料本身就沒被覆蓋

Classical Rough Set 只從「條件相同、答案也相同」的訓練資料學規則（正區域）。連續特徵切成 3 段後，很多條件相同但答案不同的資料會被排除，這些資料一開始就沒有規則。這時訓練 Coverage 和測試 Coverage 一樣低。

常見於連續特徵、資料量大。

原因二：測試出現沒見過的組合

訓練資料全部被覆蓋（100%），但規則的條件組合太具體，測試資料出現沒看過的組合就不會命中。這才是真正的「訓練有用、新資料不行」。

常見於小型、類別特徵的資料，例如最早的三個資料集。

只用訓練資料生成補充規則有條件規則命中 +0.6～+5.5pp120 組中 112 組 BA 完全沒變20 UCI、2 seeds、3 種分布

結論：Coverage 提高不等於判斷變準。既然主要原因是「連續特徵切 3 段後資料不一致」，下一步應該從源頭處理：改用依類別切點的離散化（如 MDLP），或用允許少量不一致的變精度 Rough Set（VPRS），讓邊界資料也能產生規則。

補充診斷是用 repo 現有的全量實驗程式，在可直接取得的 5 份資料（scikit-learn 內建的 Wine、Breast Cancer、Iris，以及 repo 內的 AI4I、Online Shoppers）重跑，逐筆結果；程式在 experiments/coverage_diag_20261119/。

整理成適用與失效條件

衝突率低於 1%（多數集中式）
六種方法結果幾乎一樣，選哪個都可以。
SV 簡單投票
適用：資料不均、2–5 類、類別大致平均。失效：很少大輸，但類別很多或有稀有類別時不是最好。
STD／PS 支持度投票
適用：IID、類別 6 類以上、有稀有類別（少數類 <10%）、訓練標籤有雜訊。失效：資料不均且類別平均時落後約 3–4pp。
FM 第一條命中規則
失效：衝突率 10% 以上就開始明顯落後，30% 以上有一半的情況落後 5pp 以上。
GS／PG 全域強度
適用：幾乎沒有比 STD 更好的條件。失效：資料不均且類別少時，與 FM 一樣大輸。

這些是事後依資料特性分組的觀察，不是因果結論；要變成選法規則，需要在新資料上事先固定規則再驗證。

目前的限制

  • 每個資料集只用前 6 個特徵（原始特徵數中位數 20）。最小約簡用窮舉法，特徵多就算不完。
  • 7 個資料集沒有跑完所有情境（共 95 個模型超過 45 分鐘上限），沒有列入統計，包含最大的 221 萬列資料。
  • 全量實驗是 5 個 seed；42 seeds 只有最早的三個資料集。seed 是同一份資料的不同切分，不是新資料。
  • 依老師要求以 Accuracy 排名；Accuracy 偏向多數類別，平衡正確率（BA）在大表中都有。
  • 聯邦是 3 個 Client 的模擬，沒有通訊或隱私機制。
