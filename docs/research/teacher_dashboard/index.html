01 · EXECUTIVE SUMMARY

三分鐘研究結論：我們真正驗證了什麼？

完整實驗數8,82042 Seeds × 每 Seed 210 配置
重複實驗 Seeds42 / 42正式證據載入中；不以舊硬編碼判定
無選擇器診斷1,260NONE：Coverage、Conflict，不產生預測 Accuracy
六策略分類列數7,560FIRST、SIMPLE、STD、GS、PS、PG
研究核心：Local LEM2 規則合併後通常提高覆蓋率，同時也讓更多物件命中跨決策候選。是否真正改善分類，取決於候選中是否包含真實類別，以及後續選擇策略如何計分。衝突率本身不是模型錯誤率，也不是 Rough Set 的 Boundary Region。

研究問題 A｜規則從哪裡來？

資料先切分，Reduct／LEM2 再歸納規則。Centralized 與 Federated 的差異發生在規則產生階段；不是在最後才換一個投票方法。

研究問題 B｜合併後發生什麼？

Federated 的 Local Rule Sets 先合併成全域 Rule Set。命中規則愈多，可能提高候選涵蓋，也可能引入跨類別衝突。

研究問題 C｜Conflict 後怎麼選？

NONE 只做診斷；六策略選 Winner。若正解根本不在 Candidate，改投票方式也無法救回；若正解已在候選，才能比較排序／投票策略。

報告範圍：這是三個資料集的重複切分研究。42 個 Seeds 不是 42 個獨立資料集；Full Data 是同資料回代，不能當成泛化能力；尚未補齊 LERS 原典分類與 DRSA reduct。

06 · SELECTION POLICY COMPARISON

六種方法不是在「產生規則」，而是在「如何選答案」

FIRST_MATCH

第一個匹配規則的 decision

找到第一條就返回；規則順序可能改變答案。

SIMPLE_VOTING

Score(d) = |{r ∈ M : dec(r)=d}|

命中的規則各算 1 票；忽略支持人口。

STANDARD_VOTING

Score(d) = Σᵣ weight(r)

每條規則的權重加總，可能重複計數。

GLOBAL_STRENGTH

Score(d) = Ud / Nd

某類別不重複支持人口，除以該類訓練人口。

POPULATION_STANDARD

Score(d) = Ud

以唯一支持人口取代重複支持次數。

POPULATION_GLOBAL

Score(d) = Ud² / (NdTd)

GS 分數乘以非冗餘比例 P = U/T。

07 · WHAT HAPPENS AFTER CONFLICT?

Conflict 後怎麼辦？先診斷失敗位置，再選擇改善手段

定義： M(x) 是匹配規則集合；Candidate(x) 是這些規則所提出的不同決策；若 |Candidate(x)| ≥ 2，這筆有跨決策 Conflict。六種策略處理的是 Winner，不會自動消除既有規則集合的 Conflict。
類型 A · 沒規則

No Match

M(x) = ∅。現有程式使用訓練資料多數類別 Fallback，可能剛好答對，也可能答錯。

工程措施：檢查低 Coverage 類別、離散化邊界、規則學習完整性；高風險時研究 Abstain／人工審查。

類型 B · 候選生成失敗

正確類別不在 Candidate

有規則命中，但正確類別未被任何匹配規則提出。換投票規則也無法選出不存在的答案。

工程措施：檢查 Reduct、資料偏斜、Local LEM2、Rule Union 與特徵品質。

類型 C · 衝突選擇失敗

正確類別在 Candidate，但 Winner 錯

這才是六種決策選擇策略能直接改善的部分。逐項核對命中規則、T、U、N、P、分數與同分處理。

工程措施：STD ↔ GS、PS ↔ PG 成對測試，檢查重複支持與類別不平衡。

類型 D · 選對但仍需驗證

正確選出 Winner

不能只報 Accuracy。仍要記錄這一筆有無 Conflict、是否為 fallback、對 Client 順序／Seed 是否敏感。

工程措施：建立 Rule Receipt、信心與責任追溯；未來可加入驗證後的審查 Gate。

08 · ROBUSTNESS & ABLATION

Seed 之外還要確認兩個敏感因素

① non-IID 的分配偏斜

額外七 Seeds（1～6、42）實驗，用 Dirichlet α = 0.5／0.1、C3／C5，比較 IID 分層與偏斜分派。

配置ConflictGS AccuracyGS BA
IID 分層58.1%80.0%68.5%
α = 0.580.8%66.0%56.0%
α = 0.193.7%41.6%35.2%

7 Seeds 的探索性試驗，尚不等於 42 Seeds 全部完成 non-IID。

② FIRST_MATCH 的 Client 順序

固定同一訓練資料及 Local Rules，只改 Client 規則合併順序。Seed 42 中，C2/C3/C4/C5 完整枚舉每組 2/6/24/120 種，三資料集共 456 組。

資料集，C5FIRST Accuracy 範圍
Balance Scale62.70%～71.43%
Car Evaluation83.82%～87.86%
Hayes-Roth65.38%～84.62%

順序試驗只檢驗 FIRST 的順序敏感性；不能直接外推到其他策略。

風險提醒：若要宣稱方法有效，必須區分「資料同源重複切分的穩健性」與「跨獨立資料集的可推廣性」。非 IID 的結果也提醒我們，原先 IID 的 GS 平均優勢可能不適用於嚴重偏斜的 Client。
