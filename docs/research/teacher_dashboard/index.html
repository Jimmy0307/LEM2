到底哪一種比較好？

第四件事｜拿一筆資料，讓老師真的看懂 Conflict

同一個天平，為什麼兩種規則會給不同答案？

這是舊版 Balance Scale 的真實測試資料 row_id=54，有兩種規則同時命中，分別說「向左」與「向右」。真正答案是向右（R）。

原始條件：左側重量 1、距離 3；右側重量 1、距離 5。左邊力矩 3，右邊力矩 5，所以真實答案是 R（向右）。

① 規則同時命中

有規則說 L（向左），也有規則說 R（向右）。

② 原 Standard

重複支持次數：L = 19，R = 18，所以選 L，判錯。

③ 去重後 Standard

不同支持資料：L = 16，R = 18，所以選 R，判對。

但這不是說去重一定比較好。另一筆 Balance Scale row_id=77 恰好相反：原 Standard 判對，去重後反而判錯。這說明真正的研究問題是：什麼樣的衝突與重複支持，才適合改用另一種投票方式？

老師若追問：我們如何判斷錯在規則，還是最後選答案？

先問三件事：① 有沒有規則命中？② 真實答案有沒有被任何命中的規則提出？③ 已經提出正確答案，為什麼最後還選錯？

若第②題就是「沒有」，換任何投票方法也救不了；必須回去改規則生成。若正確答案已在候選裡、最後仍選錯，才值得比較六種策略。
