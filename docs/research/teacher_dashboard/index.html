該怎麼讀「學習架構」？

本研究的比較單位是 Centralized 和 Federated C2～C5，代表規則在哪裡學、由多少個 Client 提供 Local Rules。不是網路拓樸圖的節點連線結構。

該怎麼讀「曲線指標」？

指的是 Y 軸觀測變數（Coverage、Conflict、Rule Count 或預測績效），不是要比較「曲線」本身。Seed 1～42 是重複抽樣標籤，不能解讀為隨時間增加或改良。

04 · PREDICTION CONTRACT · IMPORTANT FOR THE PROFESSOR

六策略不是只計算 Conflict：所有測試物件都會分類，衝突另行診斷

正式報告的 Overall Accuracy／Balanced Accuracy／Macro-F1 以整個測試集為評估對象；另有獨立的 Conflict-only Accuracy，只看事前判定為多候選決策的物件。兩種分母不能互換。

A｜No Match

沒有任何規則匹配，六策略均回退到訓練資料的多數類別（default_class）。這種 fallback 可能答對。

B｜No Conflict

有規則匹配，但全部命中規則只提出同一個候選決策；六策略輸出該唯一類別，即使命中不只一條規則。

C｜Conflict

有至少兩個不同候選決策。六策略在同一 Rule Set 上產生 Winner；First Match 看順序，其餘五種計分。

平票時如何選？五種計分方法以 np.isclose 判斷最高分候選；若訓練集多數類別也在平票集合就選它，否則按類別名稱的字串排序選第一個。First Match 不計票；Conflict 指標則是在策略選擇之前獨立計算。

分母：若 N0 為 No Match、N1 為匹配但單一候選、Nc 為 Conflict，則 N = N0 + N1 + Nc；Overall Accuracy = (K0+K1+Kc)/N，Conflict-only Accuracy = Kc/Nc（若 Nc=0 則未定義）。

一項重要更正：現有程式的 STANDARD 權重 Wd 統計「符合前件的訓練物件」；Population 的支持度 Td、Ud 則要求「前件成立且決策類別一致」。有不一致資料時 Wd 不必等於 Td。因此不能直接宣稱 PS 是對程式 STANDARD 權重逐項去重。
05 · CONFLICT DECISION PLAYBOOK

Conflict 不是直接「消掉」｜先判斷問題在哪個階段

當新物件 x 進來，先取得命中規則 M(x) 和候選類別 C(x)。有多個候選只代表有決策歧義，不代表已經預測錯。必須按下方順序判斷，才能對症改動規則學習或 Winner 計分。
補充：Conflict 不等於全部測試物件。無規則命中使用多數類別；有規則命中但只有一種候選時，六策略同樣輸出唯一決策。平票時五種計分策略共用相同決勝規則。查看完整分流、平票與評估分母說明 →
