05 · G7 WHAT IS / IS NOT AN ALGORITHM CONTRIBUTION

演算法性質與新穎性邊界

六種決策解析器已是明確可執行的演算法；但它們**共用同一套 Classical LEM2 規則**，不等於六個獨立規則歸納器。已驗證的結構性質包括：

Coverage/Conflict 不因六種選法而改變；無衝突物件的六方法輸出相同；任何兩種策略的不同預測比例不可能超過 Conflict Rate；已命中但正確候選不存在時，只換投票法不能創造正確答案。

因此 G7 的結構驗證與文獻對照已完成，但一般的模型選擇、Rule Pruning、Conflict-Aware Ranking 早有先例；研究要主張學術首創仍需提出新的理論機制、消融和跨獨立資料庫對比。查看形式化命題與先行研究比較。
