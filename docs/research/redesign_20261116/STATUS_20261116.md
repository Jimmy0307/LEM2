## 探索性主要發現（尚未經確認性驗證）
1. **α=0.1 的情況**
   - 80% 的配置含有 TRUE→d 規則，平均 3 個 Client 裡有 1.33 個是單類別。
   - Test Coverage 97.1%，其中 35.4 pp 只靠 TRUE 規則命中。
   - Conflict 為 61.5%；排除 TRUE 規則後降到 18.6%，也就是 42.9 pp 的 Conflict 由 TRUE 規則造成。
   - 有 34.3% 的列，正確類別之所以出現在候選中，只是因為 TRUE 規則。
2. **排除或降級 TRUE 規則對 Test BA 的影響**（α=0.1，以資料集為統計單位）
   - B2（TRUE 規則只在沒有其他規則命中時才用）：Simple Voting 提升 +2.7 pp（Holm p=0.02），Global Strength 提升 +11.3 pp（Holm p=0.007）。
   - IID 下沒有任何影響。
3. **六策略的差異大多是 TRUE 規則造成的假象**
   - α=0.1：保留全部規則時，六策略相差 9.0 pp（Friedman p=0.0001）。
   - 排除 TRUE 規則後只差 1.1 pp（Friedman p=0.84）。
4. **Control C** 的 BA 提升 +6.1 pp，但它同時改變了資料分配：Label skew（TV）從 0.42 降到 0.33，平均要重抽約 55 次。因此這不能當成規則處理本身的效果。
5. **離散化是一階影響因素**
   - Rough Set 辨識切點法（MD heuristic，集中式參考）在所有分布下都最好：IID Validation Best 72.9%，等寬3 為 64.7%。ChiMerge 排第二。
   - MDLP 對 LEM2 切得太粗。
   - 在區間數相同時，監督式切點的位置也有影響（+3 pp）。
